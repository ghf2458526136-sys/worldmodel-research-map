下载后双击 `index.html` 即可，无需服务器、无需联网。

## 图怎么读

- **横轴是时间**，但每条路线各有一条独立时间轴：不同路线之间不对齐，同一条路线内部按月份对齐。
- 只保留有论文的月份，没有论文的月份不占位，所以不会出现大片空白。
- 同一个月、同一条分支下的多篇论文纵向摞起来。
- 年份用竖向虚线切开，标在泳道上方。
- **绿色实心标签=免训**，其他颜色标签是论文的特征标签（2 到 3 个）。
- **带呼吸光圈的 8 篇是重点论文**：WorldTrace、SMART、VMem、Keepsake、WorldPlay、Rolling Forcing、ATAS、Matrix-Game 4.0。
- 点卡片从右侧滑出详情：一句话、机制、关键数字、我们自测的数字、直白讲解、链接。

## 交互

| 操作 | 效果 |
|------|------|
| 滚轮 / 触控板双指滑动 | 平移（Shift+滚轮横移） |
| Ctrl(⌘)+滚轮 / 触控板捏合 / 触屏双指 | 缩放 |
| 拖拽空白处 | 平移 |
| 双击空白 | 全览 |
| 左侧路线 / 分支 / 年份标签 | **随镜头吸附**，始终停在可视区边缘 |
| 点卡片 | 镜头飞到该卡片，右侧滑出详情，并高亮它的上下游脉络、淡化无关卡片 |
| `←` `→` | 在同一路线内按时间切换论文 |
| `/` 搜索，`Enter` 跳到首个匹配 | 实时显示匹配篇数，连线同步淡化 |
| 左下「路线导航」 | 点名称飞到该路线；点圆点显示/隐藏该路线 |
| 右下缩略图 | 点击或拖动快速定位 |
| 按时间播放 | 镜头跟随，论文按时间逐个亮起；`Esc` 停止 |
| `Esc` / 点空白 | 关闭详情 |
| URL `#论文id` | 直接打开某篇，可分享 |

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 主产物，单文件，数据内嵌 |
| `research-map.yaml` | 唯一数据源，加论文只改这里 |
| `build_map.py` | 生成器，校验素材路径后重建 HTML |

## 重新生成

```bash
python build_map.py research-map.yaml index.html "世界模型回溯记忆调研图谱" "./"
```

第 4 个参数是媒体路径前缀。本仓库为了体积没有上传视频，所以 `research-map.yaml` 里保留了 media 字段但文件不在；线上版本的 HTML 是用去掉 media 的数据单独构建的。

## 数据来源

调研报告与素材在本地 `科研/WorldModel/`，论文信息以 arXiv 原文、官方项目页和官方仓库为准。标注「我们自测」的数字是在官方 demo 视频上自行计算的量级参考，不是论文指标。

图上连线表示**机制同构**，不是引用关系——调研报告没有参考文献映射，所以没有一条边是「A 引用了 B」。
