# World Model Memory Atlas · 世界模型记忆图谱

**124 篇论文、8 条技术路线、每条路线各自的时钟——一张可以点开看方法细节的世界模型记忆图谱。**

在线打开：**https://mngli-ai.github.io/awesome-world-model-memory/**

---

## 这张图回答什么问题

视频世界模型越做越长，问题从“能不能生成”变成了“**它记不记得住、找不找得回**”。

一张地图把这件事拆开看：世界模型把历史存在哪里、用什么地址去取、什么时候会取错。收录 2023 年到 2026 年 10 月的 124 篇工作，按八条技术路线分开摆放，每条路线一条独立时间轴。

适合三类人：

- **刚进这个方向的研究者**：先看整体形状，再逐条路线读下去
- **要写综述或做选题的人**：看清哪条路线拥挤、哪条还空着
- **做工程的**：查某个方法到底怎么实现、官方有没有演示、代价是什么

## 怎么读

**八条路线**，各占一条横向泳道：

| 路线 | 篇数 | 在做什么 |
|---|---:|---|
| 几何位姿寻址 | 25 | 用相机位姿和三维几何决定取哪段历史 |
| 位置时间寻址 | 18 | 改位置编码或注意力锚点，让远期记忆落在训练分布内 |
| 评测基准 | 18 | 测回访一致性、状态演化、交互闭环 |
| 框架层 | 15 | 完整系统与产品，把状态和渲染分工 |
| 代码世界模型 | 14 | 用可执行代码维护世界状态，视频模型只负责画 |
| 训练侧 | 14 | 蒸馏、教师替换、长程训练配方 |
| 内容学习寻址 | 11 | 按内容相似度检索历史 KV 或帧 |
| 参数化记忆 | 9 | 把历史压进权重或适配参数 |

**每篇论文一张卡**，卡片上是一句话、特征标签、出现年月，以及引用速率光圈。点开有三层信息：

1. **直白讲解**：一段口语化的说明，先建立直觉
2. **影响力**：被引总数、引用速率（次/月）、图谱内被后继工作继承的次数、代码与权重的开放程度
3. **机制详解**：定位、输入输出、做法步骤、关键公式、训练与推理、与已有做法的差别、代价与局限，公式用 LaTeX 渲染
4. **证据**：官方演示视频或图片、论文与项目页、关键数字

**操作**：滚轮或 Ctrl+滚轮缩放，拖拽平移，双击空白全览，← → 切换论文，按 `/` 搜索。触屏也支持。

## 引用速率光圈

卡片外围的光晕按**引用速率**（cpm，citations per month，被引次数 ÷ 论文发表月数）分档，越亮代表每月新增被引越多：

| 引用速率 | 表现 |
|---|---|
| 0 或无数据 | 无光晕 |
| 0 < cpm < 0.15 | 细光环，浅蓝 |
| 0.15 ≤ cpm < 0.40 | 中等宽环，蓝 |
| 0.40 ≤ cpm < 1.00 | 宽环，紫 |
| cpm ≥ 1.00 | 最宽环，暖金，呼吸更快 |

用速率而不是绝对引用数，是为了不让今年的新论文全被压成 0：刚发两个月被引 3 次（1.5 次/月）比两年前被引 20 次（0.8 次/月）更热。卡片右下角同时写「被引 N · x.x/月」，被图谱内后续工作直接接续的卡片另标一枚「被继承 N」，这里的 N 只数直接后继（引用它的机制、拿它当起点），不含隔代的传递继承；传递关系另外记在面板里。124 篇里只有 10 篇速率大于 0、30 篇有直接后继，多数卡片不发光是正常的。

引用量取自 OpenAlex，按 arXiv DOI 精确匹配（`doi:10.48550/arXiv.<编号>`），124 篇里 109 篇有数；剩下 15 篇没有 arXiv 编号（产品页或博客发布），字段留空，不记为 0。

口径说明：不同数据源差异不小，例如 FramePack 在 OpenAlex 是 7，在 Semantic Scholar 是 154，Google Scholar 通常更高。这里统一用 OpenAlex，好处是 DOI 精确匹配、可复现；因此光圈适合比较**同一张图内**的相对影响力，不适合跨源对照。新论文引用少是常态，光圈只是影响力提示，不是质量判断。

## 做法扩散

每篇论文还会被归到一组**规范做法**上（28 个封闭标签，由 gpt-6-sol-pro 多标签归类，避免各写各的说法）。点开任意卡片能看到它的做法标签，点标签直接筛出同类工作。

按图谱内出现次数排，扩散最广的五种做法是：

| 做法 | 用它的论文 | 图谱内首见 |
|---|---:|---|
| 动作条件控制 | 19 | Genie 3 |
| 旋转位置编码 | 15 | Rolling Forcing |
| 全局锚点 KV | 14 | StreamingLLM |
| 结构条件渲染 | 14 | EvoWorld |
| 少步蒸馏 | 13 | CausVid |

这里的“首见”指**本图谱收录范围内**最早出现，不等于领域首创。

## 数据与准确性

- 论文条目以 arXiv 和官方项目页为准，标题、编号、日期逐条核对
- 机制描述写给第一次接触这个方向的人看，公式标注了是论文原式还是该类方法的标准写法
- **我们自测**的数字（如在官方 demo 视频上重算的 PSNR）单独标注，不与论文报告的指标混在一起
- 演示素材优先引用官方服务器直链，不做二次转码，因此清晰度以官方版本为准

## 参与进来

加一篇论文只需要改 `research-map.yaml` 里的一条记录，不需要动生成器。详细步骤、字段说明和校验命令见 **[CONTRIBUTING.md](CONTRIBUTING.md)**。

也可以通过 **[提交论文](https://github.com/mngli-ai/awesome-world-model-memory/issues/new?template=submit-paper.yml)** 表单直接提，填完由维护者核对合并。

发现坏链、错分类、写错的机制描述，都欢迎开 issue。

## 仓库结构

```
research-map.yaml           数据源：论文、路线、标签、机制、素材（唯一真相）
research-map-online.yaml    线上版：素材换成官方直链
build_map.py                生成器：yaml → 单文件 HTML
index.html                  产物：Pages 直接托管
panel_detail.js / .css      详情面板的「机制详解」折叠模块
katex_inline.css / .js      KaTeX（字体内联，离线也能渲染公式）
scripts/check_links.py      链接体检
.github/workflows/          每日体检、Pages 部署
```

本地重建：

```bash
python build_map.py research-map.yaml index.html "World Model Memory Atlas" ""
```
